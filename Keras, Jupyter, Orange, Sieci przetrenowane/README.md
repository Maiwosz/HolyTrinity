# Keras, Jupyter, Orange, Sieci przetrenowane

## Uruchamianie notatnika

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install notebook tensorflow numpy matplotlib pandas scikit-learn pillow
.venv\Scripts\python.exe -m jupyter notebook
```

Kolejne uruchomienia wymagają już tylko ostatniej komendy. Przy pierwszym użyciu InceptionV3 pobierane są wagi (~100 MB).
